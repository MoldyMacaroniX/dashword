After nearly nine months, Geometry Dash 2.209 has been released. This version adds platformer saving, custom keybinds, death tracking, death markers, editor sounds, custom platformer controls, and much more.

The update has also been released on all platforms simultaneously, including iOS, Android, and Steam!

# Geometry Dash 2.209 Features

- Platformer Saving
- Custom Keybinds
- Death Tracking
- Death Markers
- Editor Sounds and Packs
- Import/Export Editor Levels
- Auto-Save and Auto-Backup levels
- Custom Platformer Controls
- Start Position Switcher
- Group ID Names
- Improved Editor UI and Tools
- Improved SFX Browser
- Replay Daily, Weekly, and Event Levels
- Improved Following and Friends
- In-Game Notification system
- Emotes
- Improved messaging
- News tab
- Improved Options and navigation
- Bug fixes, tweaks and more!

In addition to this [Geometry Dash 2.209 changelog](https://x.com/RobTopGames/status/2110855582223569400), Geometry Dash 2.209 also left a potential accidental leak of "The Map," an upcoming feature [slated to release in 2.21](/posts/geometry-dash-2-21-release-date-everything-you-need-to-know/).

# The Map

The Map is an [upcoming Geometry Dash feature slated to release in the upcoming 2.21 update](/posts/the-map-linear-gd/), but Geometry Dash 2.209 includes a texture in the game files that looks to be from it.

![The Map](/assets/img/themapleak.webp)

The texture shows different areas that will likely feature user created platformer levels. In order, it appears the areas will consist of snow, grasslands, a swamp, a desert, a volcano, and a rocky area.

However, since [Event Levels](/posts/geometry-dash-2-207-released-on-steam/) were also originally supposed to come out in 2.21 but got released earlier, there's a chance the same will happen to The Map and we can get access to it much sooner!
